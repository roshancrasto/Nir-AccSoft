Create a complete Receipts & Payments Account Report module in the existing Angular + ASP.NET Core + SQL Server accounting application.
====================================================
REPORT NAME
====================================================
Reports
→ Receipts & Payments Account
====================================================
BUSINESS REQUIREMENT
====================================================
Generate a complete Receipts & Payments statement for a selected Financial Year.
The report should display:
LEFT SIDE:
Receipts
RIGHT SIDE:
Payments
The report should follow traditional accounting format.
====================================================
RECEIPTS DATA SOURCES
====================================================
====================================================
1. OPENING BALANCE
====================================================
Source Table:
NU_OpeningBalances
Logic:
Include all active opening balances for selected Financial Year.
Total Opening Balance =
SUM(OpeningAmount)
Exclude:
DeletedFlag = 1
====================================================
2. DONATIONS / RECEIPTS
====================================================
Source Table:
NU_Receipt
Logic:
Include ONLY receipts where:
ReceiptBook_Rno > 0
Calculation:
SUM(
    ISNULL(CashAmount,0)
    +
    ISNULL(BankAmount,0)
)
Grouped as:
Donations
Exclude:
DeletedFlag = 1
====================================================
3. BOX COLLECTION
====================================================
Source Table:
NU_BoxCollections
Include ONLY:
ConsiderForAudit = 1
Calculation:
SUM(Amount)
Grouped as:
Box Collection
Exclude:
DeletedFlag = 1
====================================================
4. GOVT GRANTS
====================================================
Source Table:
NU_GovtGrants
Include ONLY:
ConsiderForAudit = 1
Calculation:
SUM(Amount)
Grouped as:
Govt Grants
Exclude:
DeletedFlag = 1
====================================================
PAYMENTS DATA SOURCE
====================================================
====================================================
PAYMENTS
====================================================
Source Table:
NU_Payments
Calculation:
SUM(DebitAmount)
Grouped by:
Expense Category
Exclude:
DeletedFlag = 1
====================================================
IMPORTANT ACCOUNTING LOGIC
====================================================
====================================================
TOTAL RECEIPTS
====================================================
Opening Balance
+ Donations
+ Box Collection
+ Govt Grants
====================================================
TOTAL PAYMENTS
====================================================
SUM(All Payments)
====================================================
CLOSING BALANCE
====================================================
Closing Balance =
Total Receipts - Total Payments
====================================================
FINAL ACCOUNTING RULE
====================================================
Total Receipts Side MUST equal Total Payments Side.
Meaning:
Receipts Side:
Opening Balance + Income
Payments Side:
Expenses + Closing Balance
====================================================
REPORT LAYOUT REQUIREMENT
====================================================
Traditional accounting statement layout.
====================================================

====================================================

====================================================
FINAL TOTAL ROW
====================================================
